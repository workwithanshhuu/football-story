# List Logger

Routes: `/match-logger`, `/referee`  
Frame: `390 x 844`  
Traceability: `FR-4.5-01` through `FR-4.5-09`, `FR-4.12-01` through `FR-4.12-07`

## Layout

- Paper surface: `#F4F1E8`, ink text, high-contrast event colors.
- Fixed scoreboard header: venue, live pill, sync indicator, teams, scores, clock, +/- controls.
- Home/Away team switcher.
- Squad grid of named players or shirt numbers.
- Selected-player action panel with position-specific actions.
- Goal is primary; positive actions use pitch green; negative actions use coral.
- Most-recent-first event feed with timestamp and player.
- Undo bar appears after each event.

## Sheets and States

Goal detail, opponent attribution, end match, offline queue, syncing, completed, abandoned, forfeited, cancelled, and correction audit view.
