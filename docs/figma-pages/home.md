# Home

Route: `/home`  
Frame: `390 x 844`  
Traceability: `FR-4.2-01`, `FR-4.2-02`, `FR-4.2-03`, `FR-4.7-04`

## Layout

- Header: avatar, player name, location, theme toggle, search, notifications.
- Rating strip: skill value plus goals, assists, and MVP stats.
- Image-backed next-match panel: countdown, 7v7 chip, team matchup, date, venue, `Open logger`, share icon.
- Section `Matches near you`: stacked match rows with format tile, time, venue, capacity bar, price, and `Join`.
- Latest scorecard panel with final score, date, format, and MVP marker.
- Fixed bottom nav with Home active and centered create button.

## States

Authenticated data, fallback data, loading skeleton, no upcoming match, API error toast, light theme.
