# Discover

Route: `/discover`  
Frame: `390 x 844`  
Traceability: `FR-4.2-01`, `FR-4.2-02`, `FR-4.2-03`, `FR-4.3-01`

## Layout

- Header: eyebrow `DISCOVER`, title `Find your game.`, notifications icon.
- Search panel with venue/match input and filter icon.
- Format chips: All formats, 5v5, 7v7, 11v11.
- `Open matches` heading with result count.
- Match rows show format, distance, name, time, venue, capacity, price, and join action.
- Empty result panel: `No matches found` and a search/filter recovery action.
- `Bring your squad` host prompt.
- Fixed bottom nav with Discover active.

## Interactions

Typing filters immediately. Chip selection updates result styling. Match join opens a confirmation sheet. Host prompt opens `/host`.
