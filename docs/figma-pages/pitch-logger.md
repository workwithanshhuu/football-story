# Pitch Logger

Route: `/logger`  
Frame: `390 x 844`  
Traceability: `FR-4.6-01` through `FR-4.6-04`

## Layout

- Dark glass logger surface with live scoreboard and sync status.
- Visual pitch with halfway line, centre circle, penalty boxes, and formation positions.
- Player tokens use home/away colors; selected token gets volt outline.
- Bench strip below the pitch.
- Substitution interaction: select bench player, then outgoing player.
- Selected-player action bar and compact event feed below.
- Goal detail, opponent attribution, undo, and end-match sheets match the list logger.

The pitch is fixed-format and must not resize when labels, badges, or loading states change.
